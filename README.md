# 桃薰自制插件
> 用于个人练习所用、
> 
> 功能都是些小功能

## 功能

- 通过指令```/查询 <image>```来查询此图片在哪部动漫中出现，可以精确到秒
- ### 敬请期待

## 如何安装

- 通过[astrbot](https://astrbot.app/)的添加插件来安装：复制[仓库地址](https://github.com/THUTAO-Tn/astrbot_plugin_cs)到添加插件的连接即可安装

## 兼容

| 平台 | 版本 | 状态 |
|---|---|---|
